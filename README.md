## 🇧🇷 Português

### Digitaliza Orçamentos — pedidos e PDF

**Role / Papel / Rol:** Aplicação completa de pedidos/orçamentos  
**Stack:** `Python, HTML/JS/CSS, geração de PDF, Windows exe`

#### Problem / Problema
Equipe comercial precisava cadastrar produtos/clientes e emitir pedidos em PDF de forma rápida, inclusive offline em Windows.

#### Solution / Solução / Solución
Sistema web local com dashboard, validação/licenciamento e geração de PDF em duas vias, empacotado como executável.

#### Highlights
- Pedidos + PDF
- Dashboard e estatísticas
- Executável standalone
